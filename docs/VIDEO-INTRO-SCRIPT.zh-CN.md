# Playdate 项目功能介绍脚本

这支约 90 秒的视频介绍 CrankLab 项目的 Android 版，让观众了解项目定位、界面、游戏运行与摇柄操作，以及游戏库、介绍翻译和体验设置。小熊维尼麻将用于演示游戏运行与按键输入，Music Box 用于演示摇柄和音频。

主片使用模拟器录制真实界面，采用 16:9 横屏，穿插竖屏操作镜头。画面延续黄色与深灰配色。解说使用轻松、带一点俏皮感的普通话女声，像项目作者向朋友介绍自己做了哪些功能，并保留游戏声音。

## 完整解说稿

这是 CrankLab，我们做的 Playdate 模拟器项目。今天，看看 Android 版都能干点啥。

先看外观：一台能互动的 3D 掌机。转转视角，放大屏幕，再按两下按钮——小黄机的味儿，有了。

游戏也能实际跑起来。这里用小熊维尼麻将演示，方向键选牌、按键确认，画面和操作都能跟着走。

摇柄当然也安排上了。用音乐盒演示，拖动转盘，游戏里的摇柄就跟着转。来，听听它的声音。

游戏包可以自己导入，也能用内置的 PDGames 找游戏、下载运行。英文介绍看着费劲？还能翻成中文，直接在详情页里看。

想看大点？切到沉浸模式。游戏画面和按键都放大了，横着竖着都能用。屏幕上下滑，还能接着摇。

视角跟随和操作震动，也都能在设置里自己开关。怎么顺手，就怎么调。

现在还是 Beta，欢迎来试试，一起把它做得更好。

## 字幕与声音

- 字幕使用解说原文，按自然语义断句，每次最多两行，放在独立字幕区。分镜表中的画面文案作为短标题，与口播字幕区分排布。
- 口播中的 Music Box 使用“音乐盒”，Pooh Mini Mahjong 使用“小熊维尼麻将”；画面保留游戏英文标题。CrankLab、Playdate、PDGames 和 Android 按英文名称发音，3D 读作“三 D”。
- 00:43–00:51 为纯游戏声音段，配音稿在“游戏包可以自己导入”之前留出这 8 秒。解说时适当降低游戏音量，纯音乐段恢复正常音量。
- 语气像在分享项目进展：开场带一点笑意，功能说明讲清楚，“小黄机的味儿，有了”和“还能接着摇”可以稍微俏皮一点。给界面切换和操作响应留出自然停顿。
- “来，听听它的声音”之后让出音频展示段。录制与配音完成后，根据各段实际语速微调剪辑。

## 录制提示

- 模拟器使用独立演示存档与设置。准备好两款游戏的本地游戏库卡片、麻将的教程或新对局，以及 Music Box 的 Twinkle Twinkle 曲目。
- 麻将镜头保留“移动选牌、确认出牌、对局响应”的完整操作过程，使用教程或方便重新开始的对局，突出项目的游戏运行和输入功能。
- Music Box 镜头同时表现游戏画面和摇柄操作。进入沉浸式模式后，补拍摇柄转盘与屏幕上下滑动各一段素材，字幕标明两种操作方式。
- PDGames 段展示游戏目录、下载／运行入口和详情翻译。本地导入展示入口；中文介绍优先使用已有缓存。游戏运行镜头使用麻将与 Music Box。
- 视角跟随和操作震动通过设置开关展示，手机倾斜跟随仅在模拟器运动数据可用时补拍。模拟器录屏中的震动镜头展示设置入口。
- 录制前处理横屏工具栏换行和遮挡，检查两款游戏的声音与画面同步。录制窗口只展示应用内容，游戏操作按实际运行速度呈现。
- 主片明确展示 Android 版。项目另有 Switch 和 Linux 版本，首版专注 Lua 游戏，界面和功能与 Android 不同；其他平台信息可放在视频简介中，并链接各平台说明。
- 片尾保留 CrankLab 项目名和 Beta 状态。确定视频发布位置后，再补充相应的下载入口。
